# Changelog

All notable changes to Troy are listed here. Versions follow semantic versioning while the project is pre-1.0.

## 0.1.5 (2026-09-30)

Documentation and metadata release. The browser itself is unchanged from 0.1.4.

- Documentation moved to https://velofy.co/troy/.
- README: Homebrew command is now `brew install --cask velofy/tap/troy`, downloads are listed, and new Documentation and Contributing sections were added.
- `package.json`: `homepage` points at the new docs, `repository.url` points at `github.com/velofy/troy`, and `bugs.url` was added.
- Claude Code plugin manifest: added `homepage` and `repository`.

## 0.1.4 (2026-09-12)

First release published from this repository, with DMG installers for Apple silicon and Intel Macs and Windows installers.

Earlier versions (0.1.0 to 0.1.3) were not tagged in this repository.
